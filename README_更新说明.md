# BG3 构筑模拟器 V12｜目标等级驱动流程

## 新流程
1. 目标等级
2. 逐级职业路线
3. 子职业与成长节点
4. 初始属性与已解锁属性提升
5. 技能与专精
6. 职业能力
7. 戏法与法术
8. 最终构筑结果

## 核心逻辑
- 目标等级是全部计算的边界。
- 逐级职业路线必须覆盖目标等级内的每一级。
- 各职业自身等级决定子职业、专长、职业能力和可学习法术环阶。
- 角色总等级只决定熟练加值等总等级规则。
- 属性页只应用第3步已经选择的属性提升。
- 降低目标等级会移除超出目标范围的职业等级及其派生选择。

## 部署
用本包的 index.html 覆盖 GitHub 仓库根目录文件，保留 assets/spells/。
