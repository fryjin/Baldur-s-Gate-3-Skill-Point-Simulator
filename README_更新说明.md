# BG3 构筑模拟器 V10

## 上传

使用本包的 `index.html` 覆盖 GitHub 仓库根目录同名文件，保留：

- `assets/spells/`
- `data/`
- `scripts/`

Cloudflare 部署后使用 `Ctrl + F5` 强制刷新。

## 本版重点

- 以“冒险者战术典籍”为统一设计语言。
- 顶部新增 12 级角色成长轨迹。
- 中间新增每一步的目标、影响范围和完成状态。
- 右侧角色纸强化身份、完成度和当前步骤影响。
- 新增标准/紧凑密度切换。
- 改善属性、子职业、职业能力、技能、法术和专长选择卡片的层级。
- 强化键盘焦点、44px 点击区域、禁用态和 reduced-motion。
