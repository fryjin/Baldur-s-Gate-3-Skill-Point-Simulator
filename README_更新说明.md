# BG3 构筑模拟器 V14｜规则依赖链检查版

## 本次修复

- 目标等级与逐级职业继续作为唯一上游输入。
- 专长/属性提升按各职业自身4、8、12级解锁；战士6级、游荡者10级追加节点。
- 普通专长不允许重复选择，属性提升可以重复。
- 综合施法者等级改为按BG3规则计算：单一半施法/三分之一施法职业向上取整，多施法职业先累加分数再向下取整。
- 奥法骑士与诡术师最高只学习二环法术。
- 修正奥法骑士7–12级已知法术数量。
- 修正邪术师1级只有1个契约法术位；2–10级2个；11–12级3个。
- 邪术师11级六环法术改为独立“秘法奥秘”，不再作为普通契约法术。
- 术士超魔改为：2级选择2项、3级累计3项、10级累计4项；高阶超魔不会在2级提前出现。
- 游侠宿敌与自然探索者在1、6、10级分别累计1、2、3项。
- 最终构筑页新增“规则诊断”，实时检查等级、专长、技能来源、法术来源、环阶、法术位、契约魔法和职业能力完成度。

## 已知保留项

奥法骑士与诡术师的学派限制包含3级/8级全学派例外和升级替换规则。V14会明确提示，但没有强制重演每一级替换过程，避免错误删除合法的例外法术。

## 部署

用本包 `index.html` 覆盖仓库根目录同名文件。保留 `assets/spells/`。Cloudflare部署完成后执行 `Ctrl + F5`。
