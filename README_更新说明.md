# BG3 构筑模拟器 V15｜初始属性独立版

## 核心修正

初始属性配置已经移动到第一步，并与目标等级完全拆开：

1. 初始属性
2. 目标等级
3. 逐级职业
4. 子职业与专长
5. 技能与专精
6. 职业能力
7. 戏法与法术
8. 最终构筑

### 初始属性规则

- 创建角色时固定使用27点购。
- 点购基础范围为8–15。
- 创建加值为+2和+1，不能投入同一属性。
- 单项初始常规最高为17。
- 调整目标等级不会改变27点购，也不会产生新的初始点数。

### 后续属性变化

升级本身不会自动发放属性点。职业等级达到专长节点时，可以选择普通专长或属性提升专长。只有选择属性提升专长时，最终角色纸才会增加属性；该效果不会改变第一步的初始27点购。

## 部署

用本包中的 `index.html` 覆盖 GitHub 仓库根目录同名文件。保留现有 `assets/spells/`。Cloudflare Pages 部署完成后使用 `Ctrl + F5`。
