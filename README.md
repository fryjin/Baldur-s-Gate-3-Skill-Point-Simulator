# 博德之门 3 构筑规划器 · V7 M15

M15 是 PC 端“无横向交互”收口版本。构筑规则和 M13 独立移动端保持不变。

## 本轮变化

- PC 端不再要求拖动横向滚动条或使用 `Shift + 滚轮`。
- 已选职业能力改为两列自动换行，内容较多时使用纵向滚动。
- 已准备法术图标自动换行，内容较多时使用纵向滚动。
- 子职业、专长、技能来源和职业能力节点改为响应式网格。
- 目标等级和逐级职业轨迹在宽屏单行、紧凑 PC 两行展示。
- 法术环阶筛选自动换行。
- 选项宽度跟随容器，不再生成横向轨道。
- 移动端继续使用 M13 独立产品层，移动端触控筛选不受影响。

## 上传

将压缩包内文件覆盖仓库中的 V7 文件，并继续保留：

```text
assets/spells/*.png
```

入口仍为根目录 `index.html`。
