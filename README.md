# 博德之门 3 构筑规划器 · V7 M13

V7 M13 将移动端从 PC 三栏布局中完全拆出，建立独立的移动端产品层。

## 上传方式

将本目录中的文件覆盖上传到 GitHub Pages 仓库根目录。继续保留仓库已有的法术图片：

```text
assets/spells/*.png
```

入口仍为：

```text
index.html
```

## PC 与移动端结构

- `>= 768px`：继续使用 PC/平板布局。
- `<= 767px`：直接渲染独立移动端 Shell 和移动端步骤视图，不再压缩 PC 三栏。

共用内容：Store、规则计算、职业/技能/法术数据、存档、导入导出。

移动端独立内容：

- 精简顶部状态栏；
- 单列当前任务；
- 独立移动文案；
- 底部步骤操作栏；
- 详情 Bottom Sheet；
- 全屏角色纸；
- iPhone 刘海、灵动岛和 Home Indicator 安全区；
- Safari 动态视口和软键盘处理；
- iPhone 横屏紧凑布局。

## 移动端步骤

1. 目标等级：大号等级选择 + 3×4 快速等级网格。
2. 逐级职业：一次编辑一个角色等级，职业列表使用底部抽屉。
3. 升级节点：一次处理一个子职业或专长节点。
4. 分配属性：紧凑属性行，属性影响直接在页面中展开。
5. 擅长技能：按来源分阶段，两列技能选择。
6. 职业能力：按选择组逐项完成。
7. 选择法术：单列法术列表、横向筛选、Bottom Sheet 详情和已准备栏。

动态步骤逻辑继续生效：无施法能力时不会显示法术步骤；没有主动职业能力时不会显示职业能力步骤。
