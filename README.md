# BG3 构筑规划器 V7 M11

这是 V7 的第十一个开发批次，可直接部署到 GitHub Pages。

## M11 主要修复：专长全局唯一

### 普通专长不能重复选择

“警觉、幸运、战地施法者、巨武器大师”等普通专长一旦在某个成长节点选择，就会从其他成长节点的可选列表中自动移除。

例如：

```text
法师 4级：警觉
法师 8级：列表中不再出现警觉
法师12级：列表中不再出现警觉
```

### 属性提升是规则例外

“属性提升”允许在多个成长节点重复选择，因为角色需要通过多个成长节点把核心属性逐步提升到上限。属性最终值仍限制为 20。

### 旧存档自动修复

如果 M10 或更早存档中已经重复选择普通专长，M11 加载时会：

1. 保留首次选择；
2. 将后续重复选择恢复为“待选择”；
3. 重新计入左侧未完成数量；
4. 不影响其他合法专长和属性提升。

### 双层规则保护

- 选择页面会隐藏已被其他节点占用的普通专长；
- Store 层会拒绝重复写入；
- JSON 导入和旧 LocalStorage 数据会在标准化时清除重复项。
