# BG3 构筑规划器 V7 M10

这是 V7 的第十个开发批次，可直接部署到 GitHub Pages。

## M10 主要修复

### 1. 法术列表排版重构

法术卡片不再把标题、状态、说明和伤害公式挤在同一个行盒中。现在每张卡片采用独立四层结构：

- 法术名称与选择状态；
- 环阶、学派和动作；
- 一行核心说明；
- 独立的伤害/治疗公式标签。

同时修复了原先在 `span` 内嵌套段落造成的浏览器 DOM 自动纠正问题。双列法术列表、单列窄屏和移动端均使用稳定的卡片高度，不再出现文字和公式重叠。

### 2. 已选职业能力常驻右侧角色栏

右侧 `CURRENT BUILD` 区域新增“已选职业能力”横向结果栏。无论当前停留在属性、技能还是法术页面，均可看到：

- 战斗风格；
- 战技；
- 超魔；
- 魔能祈唤；
- 契约恩赐；
- 其他主动职业选择。

每项显示能力名称和当前公式，悬停或键盘聚焦可查看来源、说明和完整效果。点击后可跳转到职业能力步骤。

### 3. 战斗大师战技公式

战技不再只有法师法术显示数值。已加入：

- 绊摔攻击；
- 推击攻击；
- 缴械攻击；
- 反击；
- 威吓攻击；
- 精准攻击。

由于当前项目尚未选择具体武器类型，战技会使用准确但不虚构武器骰的表达：

```text
武器伤害（属性 +3） + 1d8
攻击检定 + 1d8
```

具体武器骰将在未来加入装备或武器选择后再计算，不会擅自假定角色使用何种武器。
