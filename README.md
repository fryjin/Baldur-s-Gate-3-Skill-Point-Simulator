# BG3 构筑规划器 V7 M9

这是 V7 的第九个开发批次，可直接部署到 GitHub Pages。

## M9 主要更新

### 1. 右侧结果补齐

右侧“决策最终效果”现在会根据当前步骤显示：

- 技能熟练与专精结果；
- 已选择的职业能力，按职业和选择组分类；
- 职业能力的具体效果、当前属性加值和伤害公式；
- 已选戏法、法术、法术书与已准备法术；
- 当前攻击、治疗和临时生命公式。

完整构筑摘要中也会持续保留已选职业能力，不再只有技能和法术。

### 2. 动态伤害与治疗公式

新增结构化效果引擎，可根据当前构筑计算：

- 戏法随角色等级成长后的骰子；
- 法术的基础伤害、治疗和临时生命；
- 施法属性、力量、敏捷或武器属性加值；
- 邪术师“苦痛魔爆”等能力带来的实际固定加值；
- 法术升环预览；
- 最低、平均和最高数值。

示例：

```text
魔能爆：2 × (1d10 + 3) 力场
疗伤术：1d8 + 4 治疗
燃烧之手：3d6 火焰
```

当前效果数据覆盖常用伤害、治疗与临时生命法术。尚未录入结构化公式的工具、控制和探索法术继续显示原始文字说明，不会伪造数值。

### 3. 伤害类型视觉系统

支持：

- 酸蚀、寒冷、火焰、闪电、雷鸣；
- 毒素、光耀、黯蚀、心灵、力场；
- 挥砍、穿刺、钝击；
- 治疗、临时生命和可选元素。

每种类型同时使用颜色、符号和中文名称，颜色不是唯一识别方式。

### 4. iPhone 移动端重构

- 顶部改为当前等级、职业路线和步骤状态；
- 左侧步骤栏改为步骤抽屉；
- 右侧结果栏改为“本步骤结果”抽屉；
- 技能、职业能力、专长和法术详情使用底部抽屉；
- 底部操作栏适配 Home Indicator；
- 顶部适配刘海与灵动岛安全区；
- 使用动态视口高度，适配 Safari 地址栏展开与收起；
- 输入框统一不低于 16px，避免 iOS Safari 自动放大；
- 键盘弹出时隐藏底部操作栏；
- iPhone 横屏使用“列表 + 当前详情”双栏。

## 图片目录

继续保留仓库原有法术图片：

```text
assets/spells/*.png
```

M9 不会覆盖这些图片。

## 部署

将压缩包内所有文件上传到仓库根目录，覆盖 M8 的同名文件，并保留现有 `assets/spells/*.png`。

入口：

```text
index.html
```
