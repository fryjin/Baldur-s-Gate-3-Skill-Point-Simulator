# BG3 构筑规划器 V7 M12

## M12 主要修复：法术列表彻底消除重叠

本批次针对法术页面顶部“已准备法术”与第一行法术卡片重叠的问题做结构级修复。

- 法术主区域由隐式 Grid 行改为纵向 Flex 布局。
- 工具栏、数量栏、已准备法术栏固定占用自身高度。
- 法术列表只占剩余空间并独立滚动。
- 法术卡片使用明确的标题、元信息、两行描述和公式四段结构。
- 双列模式的每行最小高度提升至 124px，避免伤害公式挤压文本。
- 移动端和窄屏卡片同步调整，不再复用过低的旧高度。

这是 V7 的第十一个开发批次，可直接部署到 GitHub Pages。

## M12 主要修复：专长全局唯一

### 普通专长不能重复选择

“警觉、幸运、战地施法者、巨武器大师”等普通专长一旦在某个成长节点选择，就会从其他成长节点的可选列表中自动移除。

例如：

```text
法师 4级：警觉
法师 8级：列表中不再出现警觉
法师12级：列表中不再出现警觉
```

### 属性提升是规则例外

“属性提升”允许在多个成长节点重复选择，因为角色需要通过多个成长节点把核心属性逐步提升到上限。属性最终值仍限制为 20。

### 旧存档自动修复

如果 M10 或更早存档中已经重复选择普通专长，M12 加载时会：

1. 保留首次选择；
2. 将后续重复选择恢复为“待选择”；
3. 重新计入左侧未完成数量；
4. 不影响其他合法专长和属性提升。

### 双层规则保护

- 选择页面会隐藏已被其他节点占用的普通专长；
- Store 层会拒绝重复写入；
- JSON 导入和旧 LocalStorage 数据会在标准化时清除重复项。
