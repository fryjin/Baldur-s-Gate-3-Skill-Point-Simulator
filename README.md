# 博德之门 3 构筑规划器 · V7 M14

M14 是 PC 端结构性收口版本。它不新增构筑规则，重点修复 PC 页面高度、步骤编号、法术页布局、已准备栏、详情操作区和不同桌面宽度下的信息密度。

## 本轮变化

- PC 页面固定为一屏工作区，取消浏览器整页纵向滚动。
- `STEP XX`、左侧步骤编号和底部进度统一由动态步骤列表生成。
- 法术页改为严格的四段高度结构，只有法术列表占用剩余高度。
- 已准备法术栏固定高度、仅横向滚动，并隐藏原生滚动条。
- 法术卡片使用稳定的四行内容网格，选中后不改变尺寸。
- 当前法术操作区固定在中间详情面板底部。
- `>=1600px` 显示右侧结果栏；`1280–1599px` 通过“本步结果”按需打开。
- 移动端继续使用 M13 独立产品层。

## 上传

将压缩包内文件覆盖仓库中的 V7 文件。继续保留原有：

```text
assets/spells/*.png
```

入口仍为根目录 `index.html`。
