# 博德之门 3 构筑规划器 · V7 M17

M17 修复移动端横向阶段条没有跟随当前选择的问题，基于 V7 M16 构建。

## 本轮变化

- 技能与专精切换到后续来源时，阶段条自动显示当前阶段。
- 点击底部“下一步”进入下一个未完成阶段时，当前阶段自动滚入视口。
- 子职业与成长节点、职业能力组、逐级职业点位同步采用相同行为。
- 法术环阶筛选切换后，激活筛选项保持可见。
- 激活项已经可见时不会强制居中，避免抢夺用户手动滚动位置。
- 支持 `prefers-reduced-motion`，减少动态效果时取消平滑滚动。
- PC 端和 M16 角色纸功能保持不变。

## 上传

将压缩包内容覆盖仓库中的 V7 文件，并继续保留：

```text
assets/spells/*.png
```

入口仍为根目录 `index.html`。
