# BG3 构筑规划器 V7 · 里程碑 4

这是 V7 全新架构的第四个里程碑版本，可直接部署到 GitHub Pages。

## 本轮核心调整

### 动态构筑流程

左侧步骤不再固定显示 8 项，而是根据当前职业路线自动生成：

- 始终显示：目标等级、逐级职业、属性；
- 解锁子职业或专长节点后，显示“子职业与成长”；
- 存在需要用户选择的技能来源时，显示“技能与专精”；
- 存在需要主动选择的职业能力时，显示“职业能力”；
- 当前路线获得施法能力后，显示“戏法与法术”；
- 不再设置独立的“最终构筑”步骤。

例如：

- 战士 4级：不会显示“戏法与法术”；
- 法师 4级：显示“戏法与法术”，但不会显示没有主动选择内容的职业能力步骤；
- 流程结束后，左侧停留在最后一个实际需要完成的步骤。

### 右侧实时构筑

PC 端右侧始终展示当前构筑：

- 目标等级与职业路线；
- 六项最终属性；
- 生命、护甲、先攻、法术 DC；
- 已选专长；
- 当前未完成项；
- 完整角色纸入口。

当前页面选项的详细说明显示在实时构筑下方，不再额外占用一个“最终构筑”页面。

### 职业选择可读性

逐级职业页面已移除浏览器原生下拉菜单，改为统一的职业选项网格：

- 深色背景与明确文字对比；
- 当前职业使用金色描边和勾选标识；
- 每个职业同时显示名称与玩法定位；
- PC、平板和移动端采用不同列数适配。

其他原生 Select 也统一指定深色配色，避免浅灰菜单配白字的问题。

## 法术与戏法图片

继续优先读取仓库中已经上传的图片：

```text
assets/images/spells/<spellKey>.png
```

本包不会覆盖该目录下的现有法术图片。

## 上传方式

将压缩包内容覆盖上传到仓库根目录。请保留仓库原有的：

```text
assets/images/spells/*.png
```

## 本地预览

```bash
python -m http.server 8000
```

访问：

```text
http://localhost:8000/
```

## 页面入口

```text
#/home
#/build/<id>/level
#/build/<id>/route
#/build/<id>/progression
#/build/<id>/abilities
#/build/<id>/skills
#/build/<id>/features
#/build/<id>/spells
#/character/<id>
#/library/spells
```

旧链接 `#/build/<id>/review` 会自动跳转到当前构筑的最后一个有效步骤。
