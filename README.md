# 博德之门 3 构筑规划器 · V7 M18

M18 修复移动端法术页搜索框、筛选栏与法术列表发生视觉重叠的问题，基于 V7 M17 构建。

## 本轮变化

- 将移动端法术搜索与环阶筛选重建为独立的 `m-spell-controls` 工具区。
- 工具区使用不透明背景、独立层叠上下文和固定最小高度。
- 法术列表从工具区下方正常开始，不再透出到筛选胶囊后方。
- Sticky 状态下列表可从工具区后方滚动，但不会穿透显示。
- 搜索框使用 iPhone 友好的 16px 字号和明确深色输入样式。
- 筛选按钮移除可能继承的伪元素，修复激活项下方异常装饰。
- 保留 M17 的阶段条自动定位、M16 角色纸、M15 PC 无横向交互和 M13 独立移动端产品层。
