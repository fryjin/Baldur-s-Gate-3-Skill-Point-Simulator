# 博德之门 3 构筑规划器 V8.1 · 数据与规则接轨

V8.1 是 V8 新信息架构第一次正式接入 V7 人物数据/规则的版本。

## 入口

上传到当前 V7 仓库根目录后访问：

```text
/v8.html
```

V8.1 **不替换现有 `index.html`**，因此可以和 V7 并行验收。

## 数据来源

V8.1 不复制人物规则，而是直接调用当前仓库：

- `assets/js/store.js`
- `assets/js/selectors.js`
- `assets/js/data/core.js`
- `assets/js/data/spells.js`
- `assets/js/data/resource-model.js`

因此 V7 的人物构筑仍然是人物规则的唯一数据源。

## 存储

人物：继续使用 V7：

```text
bg3-planner-v7
```

装备：V8 独立保存：

```text
bg3-planner-v8-equipment
```

这样装备系统不会修改、破坏或迁移原 V7 人物存档。

## 本地预览

`v8.html` 是正式数据接轨版本，需要和 V7 仓库文件在同一个 HTTP/GitHub Pages 环境运行，因为它直接 import V7 模块。

如果只想双击查看 V8 UI，可打开：

```text
preview_offline.html
```

该文件是离线交互样例，不读取 V7 Store。
