# BG3 构筑规划器 V7 M7

本版本重新明确三栏职责：

- 左侧：构筑步骤与完成状态。
- 中间：当前决策、选项列表、当前选项说明和选择操作。
- 右侧：当前步骤对最终构筑产生的结果，以及完整角色纸入口。

## 上传

将本目录内容覆盖上传到 GitHub Pages 仓库根目录。请继续保留原项目中的 `assets/spells/*.png`。

## 主要变化

- 法术、技能、专长、职业能力和职业路线详情移入中间决策区。
- 右侧不再显示当前选项描述或选择按钮。
- 右侧按步骤显示最终等级、职业构成、属性、技能、能力或法术结果。
- PC 宽屏保持三栏；平板将当前详情放到中间下方；移动端仍使用详情底部抽屉。
